# 4. 最终出口（P3.0 ACCEPTED）

1. B0/B1/B2 三批全部 PASS；
2. 性能预算四项（PERF-1~3 + 模糊 P95）全部实测达标并记录在案；
3. VR 基线 = 亮/暗双套 × 10 场景，diff 干净；
4. UI-CONTRACT / 六份 FROZEN 契约零语义变更（评审确认）；
5. `docs/phase/status.md` 中 P3.0 三批标记 ACCEPTED；
6. 后置项（剪贴板历史/snippets/富结果实现/Marketplace）全部登记于
   设计规范 §9 与 phase/status.md，无悬空。

# 5. NOT ACCEPTED 触发条件（任一即拒）

- 模糊匹配引入非确定性或 IO；
- Answer 求值路径出现任何 Effect/网络/文件访问；
- VR 基线无法确定性重生成（动画泄漏）；
- popup 显示性能退化超出既有预算；
- 任何绕过 Resolver → Engine 的执行捷径；
- 设置写入触碰白名单外字段或非原子写入。
