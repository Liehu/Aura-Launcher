# 2. 执行纪律

沿用 P3.0 惯例（契约先行 / 小步提交 / Gate 命令 / 文档对齐 /
DoD），增补：

1. **窗口安全三查**（凡触 Win32 窗口的任务，Gate 必查）：
   只操作宿主 spawn 的 pid 的窗口；提权目标拒绝且报错；
   所有 `Set*` 调用有失败日志。
2. **UIPI 实验记录**：B2 的提权/UWP 行为必须写入批次文档
   （实测矩阵，不允许"应该可以"）。
3. **多窗口纪律**：第二窗口的所有 UI 变更走
   `slint::invoke_from_event_loop`；Weak 升级失败静默丢弃（与弹窗一致）。
4. registry 写操作（启停/信任）必须经
   `launcher-core::providers::plugin_registry` 公共 API——
   禁止直连 SQLite。

# 3. 允许与禁止

**允许**：新 Slint 窗口组件；`launcher-plugin-host` 暴露 pid；
manifest 加法性字段；`win_platform.rs` 扩展 Win32 窗口工具
（枚举/置顶/前台监听——全部进程外）。

**禁止**：DLL 注入 / SetWindowsHookEx 进他进程 / 修改他进程内存；
触碰非宿主 spawn 进程的窗口；WebView；改六份 FROZEN 契约语义
（ADR-0019 为加法性入口）。

# 4. DoD（单任务级）

实现 + 单测/手工验证记录 + 全量 gate 绿 + 涉及 Win32 的附
失败路径说明；UI 任务附暗/亮两套截图说明（或 VR 覆盖说明——
管理窗口 v1 不进 VR 基线，走手工清单）。
