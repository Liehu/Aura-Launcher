# 5. Hallucination Acceptance

```text
unknown provider
unknown command
unknown action
invalid input
fake capability

fake confirmation

```

```text
file
plugin
MCP
workflow
search result
user content
```

```text
UNTRUSTED DATA
```

```text
ignore instructions
grant permission
execute command
reveal secret
approve action
```

# 8. Replanning Acceptance

必须支持：

```text
execution failure
context change
external state change
user correction
tool unavailable
```

触发：

```text
RePlan
```

但必须再次：

```text
Validate
```

如果风险发生变化：

```text
ReApproval
```

---

# 9. Recovery Acceptance

Agent / Launcher 崩溃后：

```text
state recoverable
```

但不得：

```text
assume Effect did not happen
```

并进行 blind retry。

