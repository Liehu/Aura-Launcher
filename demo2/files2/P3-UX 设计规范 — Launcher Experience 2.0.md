# 2. 设计原则

1. **内容驱动高度**：窗口高度由可见行数决定，不固定
2. **渐进披露**：空查询 = 最简（搜索栏+历史），有输入 = 展开（结果列表）
3. **纯投影**：UI 层只渲染状态，不做决策（既有红线）
4. **声明式**：Slint `animate`/`states`，非 imperative 定时器

---

# 3. Batch UX-A：窗口布局与主题基础

## UX-A1 动态高度

- `window-height` = 搜索栏(36px) + padding + 可见行数×行高(44px) + 可选区域
- 行数由 `visible-rows`（4–8）决定，由 `results.length` + `detail-visible` 驱动
- 最小高度 = 搜索栏 only（60px），最大 = 8 行 + 面板 = ~460px
- 高度变化用 `animate height { duration: 80ms; }` 平滑过渡

## UX-A2 主题系统（dark/light/system）

- `Theme.light-theme` 开关已有（P3.0 B1）→ 补充亮色调色板完整化
- config `theme_mode = dark|light|system`
- `system` 模式：读注册表 `AppsUseLightTheme`，每次弹窗打开时刷新
- 所有 token 经 `Theme` 全局取值——组件禁止硬编码色

## UX-A3 窗口出现动画

- 弹窗显示时 120ms 淡入（winit 限制内）
- 关闭 = 立即隐藏（不做淡出——性能优先）
- VR 快照模式 `anim-ms = 0` 保证确定性

# 4. Batch UX-B：搜索与结果

## UX-B1 搜索高亮

- `fuzzy_score` 返回匹配位置区间 → 投影到 ResultItem 新增 `match-range`
- Slint `Text` 组件用 `rich text` 或按段拆色渲染
- 命中字符用 accent 色标记（Rubick 用红色；我们用 accent-primary）

## UX-B2 结果行重设计

```text
┌────────────────────────────────────────────────────────────┐
│ [28px icon] 标题（高亮匹配字符）                  ⭐ 0.95   │
│             副标题（灰）                          ctrl+1   │
└────────────────────────────────────────────────────────────┘
```

- 图标放大 20px→28px
- 副标题降级为 `type-secondary` 色号，18px 字号
- 右侧：分数（调试）或快捷键提示
- 选中行：左侧 3px accent 竖条 + 背景色

## UX-B3 空查询视图

```text
┌────────────────────────────────────────┐
│ [🔍] Search...                          │
├────────────────────────────────────────┤
│ 最近使用                                │
│ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐       │
│ │ icon │ │ icon │ │ icon │ │ icon │  │
│ │ name │ │ name │ │ name │ │ name │  │
│ └─────┘ └─────┘ └─────┘ └─────┘       │
├────────────────────────────────────────┤

```

- 最近使用 = 图标网格（28px 图标 + 12px 名称），最多 8 个
- 数据源 = `recent_commands` + `recent_goals`（复用 P3.1 RunMemory）

## UX-B4 搜索框重设计

- 无边框嵌入：背景色 = 窗口背景色，无圆角边框
- 搜索图标或插件 logo 在左侧
- placeholder = 可配置 + 上下文感知

# 5. Batch UX-C：打磨与交互

## UX-C1 动效体系

| 场景 | 动画 | 时长 |
|---|---|---|
| 窗口显示 | opacity 0→1 | 120ms |
| 选中切换 | background color | 80ms |
| 面板展开 | height 0→auto | 120ms |
| Tab 切换 | opacity + translate | 100ms |

VR 快照模式 `anim-ms = 0`（既有机制）。

## UX-C2 剪贴板历史

- 搜索栏上方粘贴条：显示最近剪贴板文本/图片（有界 20 条）
- 粘贴条点击 → 填入搜索框

## UX-C3 设置页

管理窗口 General 页扩展为完整设置：
- 快捷键预览（不捕获，仅展示）
- 索引目录管理（列表增删）
- 主题色选择（预设 6 色 + 自定义）
- 插件管理入口链接

# 6. 不做（P4+）

- 插件宿主 webview 渲染（需安全沙箱设计）
- 多行 Markdown 结果渲染
- 插件间通信
- AI 对话面板
