# 5. 最终出口（P3.1 ACCEPTED）

1. B0/B1/B2 PASS；B3 PASS 或降级记录为 EXPERIMENTAL；
2. 无注入式 hook（代码评审确认：无 SetWindowsHookEx / 无 CreateRemoteThread
   / 无 WriteProcessMemory）；
3. 窗口操作 pid 边界硬校验有测试佐证；
4. 弹窗 VR（dark+light）diff 干净；
5. `docs/phase/status.md` P3.1 标记 + 批次文档齐。

# 6. NOT ACCEPTED 触发条件（任一即拒）

- 出现任何注入式 hook 或触碰非宿主进程窗口的代码路径；
- 管理窗口破坏弹窗三 Mode 或 VR 基线；
- 插件禁用不即时生效（仍需重启）；
- 隔离插件可被一键直接启用（生命周期红线）；
- WinEventHook 线程出现忙等/空转 CPU。
