**阶段：P3.0 Adaptive Foundation**

# 1. 文档目的

本文件冻结 P3.0 的核心数据模型、接口边界、生命周期、持久化语义、Generation、Identity、Privacy 以及与 P2.5–P2.10 的连接方式。

```text

```

# 2. 设计原则

P3.0 必须遵守：

```text
Prediction ≠ Authorization
Context ≠ Capability
Memory ≠ Authority
Planning ≠ Execution
Observation ≠ Truth
Learning ≠ Policy
Suggestion ≠ Command
Pattern ≠ Intent
Goal ≠ Effect
```

以及 P2.10：

```text
Proposal ≠ Effect
Capability ≠ Authority
Trust ≠ Authority
Workflow ≠ Effect Authority
```

最终 Effect：

```text
Producer
→ Resolver
→ Validator
→ Policy
→ Approval
→ ActionEngine
→ Effect
```

# 5. Generation Namespace

P3.0 建议至少：

```text

RoutineGeneration

```

Generation 只表示：

> committed state version。

禁止：

```text

generation = request count
```

失败提交不增加 generation。



> 系统对某个判断的信心。


# 80. Persistence Boundary

允许持久化：

```text
Goal
Plan
Memory
Pattern
Routine
Feedback
Selected Observation
```

默认禁止持久化：

```text
SystemAuthorization
native HANDLE
HWND
process handle
capability token
raw Clipboard secret
ephemeral ContextSnapshot
```

---

# 81. Serialization Boundary

所有跨进程/跨版本模型必须：

```text
schema_version
```

例如：

```rust
pub struct PersistedMemory {
    pub schema_version: u32,
    ...
}
```

未来版本不允许默默解释旧字段。

---

# 82. Migration

P3.0 Migration 必须：

```text
read old
→ validate
→ transform
→ validate new
→ commit
```

失败：

```text
old state retained
```

---

# 83. Deletion Semantics

用户删除：

```text
Memory
Pattern
Routine
```

必须删除或失效：

```text
derived index
cache
suggestion references
prediction references
```

不能出现：

```text
Memory deleted
→ cached suggestion continues using it
```

---

# 84. Reset Semantics

至少支持：

```text
reset_session_memory
reset_user_patterns
reset_routines
reset_adaptive_ranking
reset_all_adaptive_state
```

Reset 必须产生：

```text
new generation
```

成功 reset 后旧 cache 不能继续生效。

默认：

```text
local
```

Remote AI 只能接收经过：

```text
classification
→ minimization
→ redaction
```

# 100. P3.0 核心结论

P3.0 的数据模型必须保持：

```text
Observed State
    ↓
Inferred State
    ↓
Predicted State
    ↓
Suggested Action
    ↓
Planned Action
    ↓
Authorized Effect
```

这是六种不同语义。

绝不能压缩成一个：

```text
AIResult
```

也不能压缩成：

```text
Action
```

最终：

> **P3 的智能层可以越来越主动，但主动性只能增加“推荐和计划质量”，不能通过数据模型偷偷获得 Effect Authority。**
