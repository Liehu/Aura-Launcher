# 一个实现上的纪律

这阶段建议严格遵守：

```text
Primitive
    ↓
只解决视觉表现
```

不要让 primitive 反过来加入业务逻辑。

例如：

```text
SelectedMarker
```

只接受：

```text
visible
```

不要让它自己判断：

```text
index == selected_index
```

再比如：

```text
StateSymbol
```

只接受：

```text
symbol / state presentation
```

不要让它理解：

```text
WorkflowStepState → 自己决定是不是失败
```

这样可以保持：

```text
Presentation Model
        ↓
Primitive
        ↓
Slint
```

而不会重新形成一层 UI 业务逻辑。
