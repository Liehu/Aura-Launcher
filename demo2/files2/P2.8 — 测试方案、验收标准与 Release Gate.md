# 28. P2.8 结束后的架构形态

完成 P2.8 后：

```text
                 ┌──────────────┐
                 │     User     │
                 └──────┬───────┘
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
       Search        Workflow        AI
          │             │             │
          └─────────────┼─────────────┘
                        ▼
                Proposal / Command
                        │
                        ▼
                 Validation Layer
                        │
                        ▼
                  Trust / Policy
                        │
                        ▼
                   Action Layer
                        │
                        ▼
                     Effect
                        │
              ┌─────────┴─────────┐
              ▼                   ▼
           Plugin           File/System
          Runtime             Effects

Plugin Ecosystem:
Repository
Package
Trust
Dependency
Install
Upgrade
Rollback
Audit
```

因此：

```text
P2.4 = Plugin Control Plane
P2.8 = Plugin Ecosystem / Supply Chain
```

两者职责不能混为一谈。

P2.8 最终解决的是：

> **插件从哪里来、是否可信、能否安装、为什么能安装、安装了什么、升级后是否正常、出问题如何恢复，以及整个过程能否被审计。**
