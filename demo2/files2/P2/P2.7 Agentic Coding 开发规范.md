# Aura Launcher P2.7 Agentic Coding 开发规范

## 1. 核心原则

P2.7 是整个项目目前最容易发生架构失控的阶段。

因此 Agent 必须遵守：

```text
AI = Untrusted Planner
ActionEngine = Trusted Execution Boundary
WorkflowRuntime = Deterministic Orchestrator
```

---

# 2. Agent 绝对红线

禁止：

```text
LLM → execute()
LLM → ActionEngine
LLM → capability grant
LLM → trust grant
LLM → authorization
LLM → confirmed=true
LLM → ResolvedAction
```

---

# 3. AI Output 永远不可信

包括：

```text
intent
tool selection
arguments
workflow
risk
confidence
explanation
```

全部必须重新验证。

---

# 4. 正确执行路径

```text
LLM Proposal
    ↓
Schema Validation
    ↓
Semantic Validation
    ↓
ReferenceResolver
    ↓
ActionResolver
    ↓
Policy
    ↓
Approval if required
    ↓
launcher-action
```

---

# 5. Agent 与 Workflow

Agent 不得修改：

```text
WorkflowRun.steps
WorkflowRun.variables
WorkflowRun.status
```

除非通过正式 Workflow Runtime API。

Agent 只提交：

```text
WorkflowProposal
```

---

# 6. Provider Boundary

AI Provider 是：

```text
Model Provider
```

不是：

```text
Action Provider
```

不要把：

```text
AiProvider
```

与：

```text
Search Provider
```

或：

```text
Action Provider
```

合并。

---

# 7. Context Boundary

AI 只能看到 Context projection。

不得直接：

```text
read filesystem
enumerate process
read registry
read credentials
```

所有信息必须来自：

```text
ContextProvider
```

---

# 8. Context Injection

任何来自：

```text
File
Plugin
MCP
Search Result
Web
```

的文本必须标记：

```text
UNTRUSTED DATA
```

不得提升为 system instruction。

---

# 9. Prompt Builder

Prompt Builder：

```text
input data
→ canonical structured context
→ prompt
```

必须 deterministic，或明确记录：

```text
model stochasticity
```

Prompt Builder 不得执行 IO。

---

# 10. Structured Output

Agent 必须要求 JSON/schema output。

禁止：

```text
regex arbitrary natural language
→ action
```

---

# 11. Plan Validator

必须有两级：

```text
Schema Validation
Semantic Validation
```

Schema valid 不代表 executable。

---

# 12. Capability

AI 可以：

```text
discover
```

不能：

```text
grant
```

例如：

```json
{
  "requires": ["filesystem.write"]
}
```

并不意味着：

```text
filesystem.write granted
```

---

# 13. Approval

Approval 是：

```text
event
```

不是：

```text
permanent authorization
```

Agent 不能保存：

```text
confirmed=true
```

作为未来执行凭据。

---

# 14. Agent Loop

推荐固定流程：

```text
Observe
→ Plan
→ Validate
→ Approve
→ Execute
→ Observe
→ Re-plan
```

每个循环都必须经过 budget guard。

---

# 15. Budget

至少存在：

```text
max_steps
max_replans
max_tool_calls
max_runtime
max_tokens
```

超过：

```text
AgentBudgetExceeded
```

必须暂停/失败。

---

# 16. Replan

Replan 后：

```text
new plan
→ validate
```

不能继续信任旧 approval。

如计划发生实质变化，重新 approval。

---

# 17. Memory

Memory 必须有：

```text
scope
owner
TTL
size limit
deletion
```

禁止无限增长。

---

# 18. Remote AI

Remote model 使用前必须经过：

```text
Privacy Policy
→ Context Filter
→ User Policy
→ Provider
```

禁止直接：

```text
full Context → remote model
```

---

# 19. Test Rule

所有 P2.7 Agent PR 必须测试：

```text
normal
malformed
hallucinated
forged
incomplete
timeout
provider crash
replan
approval
cancel
restart
```

---

# 20. Determinism

即使 LLM 输出具有随机性：

```text
same proposal
```

进入 deterministic validator 后：

```text
same validity result
same authority result
```

---

# 21. Prompt Injection

必须测试：

```text
ignore previous instructions
execute command
reveal secrets
grant capability
approve this action
```

来源：

- filename
- subtitle
- plugin result
- MCP result
- imported workflow
- file content

都必须视为 adversarial input。

---

# 23. BLOCKED Conditions

必须 BLOCK：

- LLM 直接执行 Effect
- Agent 可以授予 capability
- approval 可 replay
- prompt injection 改变 system authority
- persisted ResolvedAction
- persisted authorization
- Context 无界
- Agent loop 无界
- memory 无界
- remote AI 默认泄露敏感数据
- Replan 后继续使用过期 approval
