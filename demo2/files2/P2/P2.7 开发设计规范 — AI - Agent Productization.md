## AI / Agent Productization

**状态：DRAFT v0.1**

**基线：P2.6 Workflow 2.0**

**工作目录：**

```text
demo2/native-launcher/
```

---

# 1. 阶段定位

P2.7 是 Aura Launcher 第一个正式进入：

```text
AI
Agent
LLM Planning
Natural Language Intent
```

的产品阶段。

但 AI/Agent 必须建立在 P2.5 Search Intelligence 与 P2.6 Workflow 2.0 已冻结的基础设施之上。

核心原则：

> **AI 可以理解、规划、提案，但不能直接拥有执行权。**

# 2. P2.7 核心目标

## 2.1 Natural Language

用户可以使用：

```text
“打开今天修改过的 PDF”
“把桌面上的截图整理到 Pictures”
“启动开发环境，然后打开项目”
“帮我备份今天的工作文件”
```

```text
Intent

Context

Expected Outcome
```

# 4. AI 的职责

AI 可以：

- 理解自然语言
- 推断用户意图
- 提取实体
- 选择候选工具
- 生成 Workflow Proposal
- 生成 Action Proposal
- 解释计划
- 识别缺少的信息
- 根据执行结果重新规划

AI 不可以：

- 直接执行 Action
- 授予 capability
- 修改 trust
- 修改 authorization
- 设置 `confirmed=true`
- 构造可信 `ResolvedAction`
- 修改 Workflow Run 状态
- 绕过 ActionResolver

```text
              ↓
┌──────────────────────────┐

              ↓
┌──────────────────────────┐

              ↓
┌──────────────────────────┐

              ↓
┌──────────────────────────┐

      existing authority
```

# 6. Agent Runtime vs AI Planner

必须分离：

```text
AI Planner
```

与：

```text
Agent Runtime
```

AI Planner：

```text
Goal
→ Plan
```

Agent Runtime：

```text
Plan
→ Observe
→ Execute
→ Observe
→ Re-plan
```

二者不能合成一个“LLM loop”。

---

# 7. Proposal Model

建议：

```rust
pub struct AgentProposal {
    pub proposal_id: ProposalId,
    pub session_id: AgentSessionId,
    pub user_goal: String,
    pub intent: AgentIntent,
    pub plan: Vec<PlanStep>,
    pub explanation: Option<PlanExplanation>,
}
```

Proposal：

```text
DATA
```

不是：

```text
AUTHORIZATION
```

---

# 8. Plan Step

```rust
pub struct PlanStep {
    pub step_id: PlanStepId,
    pub action_ref: ActionReference,
    pub input: Value,
    pub rationale: Option<String>,
    pub requires_approval: bool,
}
```

重要：

`action_ref` 是逻辑引用。

不得直接保存：

```text
ResolvedAction
```

---

# 9. AgentIntent

建议：

```rust
pub enum AgentIntent {
    Search,
    Open,
    Create,
    Modify,
    Move,
    Copy,
    Delete,
    Configure,
    Automate,
    Explain,
    Unknown,
}
```

Intent 只表达：

```text
用户希望发生什么
```

不表达：

```text
当前是否有权执行
```

---

# 10. Context Assembly

Agent 的输入必须经过 Context Builder。

Context 来源：

```text
Current Query
Current Application
Current Explorer Folder
Selected Items
Recent Search
Recent Workflow
Relevant Commands
Relevant Files
User Preferences
```

每个 Context Item 必须拥有：

```text
source
timestamp/generation
confidence
scope
```

---

# 11. Context Security

AI 不应直接读取：

```text
filesystem
process memory
credentials
tokens
private application state
```

只能读取经过 Context Provider 明确定义的 projection。

模型看到的是：

```text
Context View
```

而不是：

```text
System State
```

---

# 12. Context Budget

必须 bounded：

```text
max_context_items
max_context_bytes
max_prompt_tokens
max_tool_descriptors
max_history_items
```

避免：

```text
全盘文件
+
全部搜索结果
+
全部历史
→ LLM
```

---

# 13. Tool / Capability Discovery

AI 可以看到：

```text
Tool Catalog
Action Catalog
Workflow Catalog
Provider Catalog
```

但：

> Catalog visibility ≠ capability grant。

Provider/Plugin metadata 不能直接变成授权。

---

# 14. Tool Selection

Planner 输出：

```text
tool reference
```

而非：

```text
executable object
```

例如：

```json
{
  "provider_id": "files",
  "command_id": "move",
  "action_id": "move"
}
```

之后必须重新：

```text
ReferenceResolver
→ ActionResolver
```

---

# 15. Plan Validation

LLM 输出永远不可信。

必须经过：

```text
Schema Validation
    ↓
Reference Validation
    ↓
Input Validation
    ↓
Workflow Validation
    ↓
Capability / Policy Validation
```

任何失败：

```text
ProposalRejected
```

不得自动“猜着修”。

---

# 16. Structured Output

LLM 输出必须使用严格 schema：

```json
{
  "intent": {},
  "goal": "",
  "steps": [],
  "questions": [],
  "requires_approval": true
}
```

禁止解析：

```text
“我建议你先……”
```

然后从自然语言中猜 Action。

---

# 17. Plan Confidence

不要让：

```text
LLM confidence = authorization
```

二者完全分离：

```text
confidence
=
AI belief
```

而：

```text
authorization
=
ActionResolver / Policy
```

---

# 18. Clarification Loop

当用户目标不完整时：

```text
User Goal
   ↓
Planner
   ↓
Missing Information
   ↓
Clarification
   ↓
Updated Context
   ↓
Planner
```

例如：

```text
“备份我的项目”
```

Planner 发现缺少：

```text
destination
scope
retention
```

必须询问，而不是自行猜测高风险参数。

---

# 19. Approval Classification

P2.7 建立 AI-specific risk classification：

```text
RiskLevel
├── L0 Informational
├── L1 Read-only
├── L2 Reversible
├── L3 Destructive
└── L4 Sensitive / Privileged
```

建议：

| Risk | 默认 |
|---|---|
| L0 | 自动 |
| L1 | 自动 |
| L2 | 可配置 |
| L3 | Approval |
| L4 | 强 Approval |

真正能不能执行仍由 ActionResolver / Policy 决定。

---

# 20. Plan Approval

用户看到：

```text
Goal
↓
Plan
↓
Affected Objects
↓
Risk
↓
Expected Effects
```

例如：

```text
1. 找到 Desktop 中今天创建的 PDF
2. 创建 Pictures/Today
3. 将 8 个文件移动到该目录
```

用户可以：

```text
Approve
Edit
Reject
```

---

# 21. Approval Boundary

Approve 后：

```text
Proposal
→ WorkflowDefinition / ActionProposal
→ runtime
```

不得：

```text
Approve
→ mark all future Actions authorized
```

Approval 必须：

```text
run-scoped
step-scoped
event-scoped
```

---

# 22. Agent Runtime

Agent Runtime 才允许：

```text
Observe
→ Plan
→ Execute
→ Observe
→ RePlan
```

但每次执行必须重新经过：

```text
ReferenceResolver
→ ActionResolver
→ ActionEngine
```

---

# 23. Agent Loop

推荐：

```text
while not terminal:
    observe()
    plan()
    validate_plan()
    request_approval_if_required()
    execute_one_step()
    observe_result()
    decide_next_step()
```

禁止：

```text
LLM
→ generate arbitrary tool call
→ execute
→ trust returned authorization
```

---

# 24. Agent Step Budget

Agent 必须 bounded：

```text
max_steps
max_replans
max_tool_calls
max_runtime
max_tokens
max_parallel_actions
```

超过任何一个限制：

```text
AgentBudgetExceeded
```

进入安全暂停。

---

# 25. Replanning

Replan 可以由：

- Action failure
- Context change
- External state change
- User correction
- Tool unavailable

触发。

但：

> Replan != 自动授权。

新的 Plan 必须重新 validate。

---

# 26. Agent Memory

P2.7 第一版只支持：

```text
Session Memory
Run Memory
Optional User Preference
```

不默认启用无限长期 memory。

Memory 必须：

- bounded
- explicit
- user-visible
- deletable
- scoped

---

# 27. AI Provider

定义：

```rust
pub trait AiProvider {
    fn complete(&self, request: AiRequest) -> Result<AiResponse, AiError>;
}
```

Provider 可为：

- local LLM
- remote LLM
- test/mock provider

核心 Launcher 不依赖具体模型。

---

# 28. Model Runtime

严禁默认常驻：

```text
Python
Node
LLM process
```

推荐：

```text
On Demand
→ Request
→ Complete
→ Idle shutdown
```

保持 Launcher idle resource budget。

---

# 29. Model Capability

AI Provider 必须声明：

```text
model_id
context_window
structured_output
tool_use
vision
reasoning
local/remote
```

这些属于 model metadata。

不是 Action capability。

---

# 30. Privacy

默认策略：

```text
Local-first
```

如果使用 Remote LLM：

必须明确：

```text
data leaves machine
```

并可：

```text
disable remote AI
```

默认不发送：

- credentials
- tokens
- full filesystem
- arbitrary process memory

---

# 31. Prompt Boundary

Prompt Builder 必须独立于：

```text
ActionResolver
```

Prompt 中展示：

```text
Tool metadata
```

必须明确：

```text
untrusted declaration
```

避免 Prompt Injection 将文本变成 authority。

---

# 32. Prompt Injection Defense

输入可能来自：

- 文件名
- 文件内容
- 网页
- 插件结果
- MCP
- 用户文本

这些全部视为：

```text
UNTRUSTED DATA
```

不能让：

```text
“ignore previous instructions”
```

成为 system instruction。

---

# 33. Output Validation

LLM Output：

```text
untrusted
```

必须：

```text
Parse
→ Schema Validate
→ Semantic Validate
→ Capability Validate
→ Action Resolve
```

任何未知字段应安全忽略或拒绝，不能改变 authority。

---

# 34. Agent / Workflow Integration

推荐：

```text
Agent
 ↓
WorkflowProposal
 ↓
WorkflowDefinition
 ↓
WorkflowValidator
 ↓
WorkflowRuntime
```

Agent 不直接驱动 Workflow internal state。

---

# 35. MCP Integration

MCP 继续作为：

```text
Provider / Tool Metadata Source
```

而不是新的 execution authority。

必须：

```text
MCP Tool
→ Action Reference
→ ActionResolver
```

不能：

```text
LLM → raw MCP → effect
```

---

# 36. Agent State

建议：

```rust
pub enum AgentRunStatus {
    Created,
    Planning,
    AwaitingApproval,
    Executing,
    RePlanning,
    Paused,
    Succeeded,
    Failed,
    Cancelled,
}
```

---

# 37. Agent Observability

至少记录：

```text
agent_session_created
agent_plan_generated
agent_plan_rejected
agent_approval_requested
agent_approval_received
agent_step_started
agent_step_completed
agent_step_failed
agent_replanned
agent_budget_exceeded
agent_run_succeeded
agent_run_failed
agent_run_cancelled
```

禁止默认持久化完整敏感 Prompt。

---

# 38. Metrics

至少：

```text
llm_latency
prompt_tokens
completion_tokens
planning_latency
validation_latency
tool_selection_count
replan_count
approval_wait_ms
agent_run_latency
budget_exceeded_count
model_error_count
```
