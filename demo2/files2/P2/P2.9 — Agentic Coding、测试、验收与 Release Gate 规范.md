# 2. Agent 第一原则

Agent 不允许直接从任务：

```text
“实现关闭窗口”
```

推导为：

```text
调用 Win32 CloseWindow
```

必须先找到：

```text
WindowTarget
WindowIdentity
Capability
Risk
Policy
Confirmation
Execution
Audit
```

---

# 3. Native API 禁止扩散

禁止业务层出现大量：

```text
HWND
HANDLE
PROCESS_INFORMATION
HGLOBAL
Win32 constants
```

业务层只能看到：

```text
Domain Model
Provider Trait
SystemCommand
```

---

# 4. Windows Adapter

只有 Adapter 可以直接依赖：

```text
Win32
COM
Shell API
Windows Runtime
```

例如：

```text
launcher-system
     ↓
WindowsSystemProvider
     ↓
Windows Adapter
```

不能：

```text
launcher-ai
     ↓
winapi
```

---

# 5. Target Safety

所有 Agent 都必须考虑资源发生变化：

```text
resolve
    ↓
time passes
    ↓
target changed
    ↓
execute
```

因此执行前必须：

```text
re-resolve / revalidate
```

---

# 6. Process Agent

必须验证：

```text
PID
+
Process Identity
```

禁止：

```text
terminate(pid)
```

作为唯一安全校验。

测试至少包括：

```text
PID reuse
process exited
process restarted
access denied
protected process
timeout
```

---

# 7. Window Agent

测试：

```text
window closed
window recreated
HWND reused
foreground changed
title changed
process changed
```

不能把：

```text
title = "Chrome"
```

当作唯一目标。

---

# 8. File Agent

所有输入路径：

```text
Normalize
Canonicalize
Validate
Policy
```

测试：

```text
../
..\ 
UNC
device path
junction
symlink
reparse point
case variation
alternate path
```

# 9. Destructive Effect Agent

凡是：

```text

terminate
```

必须验证：

```text
risk
policy

target
```

# 10. AI Agent

AI 只能产生：

```text
Proposal
```

不能产生：

```text
HANDLE
HWND
PowerShell
Win32 function
native command
```

---

# 11. Plugin Agent

Plugin 调用：

```text
Capability API
```

不能：

```text
raw OS API
```

在 P2.9 中，Plugin Runtime 的系统访问必须经过：

```text
Plugin
→ Capability Request
→ Policy
→ System Provider
```

---

# 12. Workflow Agent

Workflow 中：

```text
Reference
```

必须可长期持久化。

以下不得持久化：

```text
HWND
HANDLE
PID-only identity
clipboard pointer
native object
```

---

# 13. Confirmation Agent

Confirmation 必须：

```text
bound to:
    actor
    request
    target
    run
    command
    expiry
```

因此：

```text
confirmation A
```

不能被：

```text
command B
```

重放。

---

# 14. Race Test

P2.9 必须大量使用竞态测试。

例如：

```text
resolve window
→ close window
→ execute
```

或者：

```text
resolve process
→ process exits
→ new process reuses PID
→ execute
```

正确结果：

```text
StaleTarget
```

而不是误操作新对象。

---

# 15. Retry Agent

必须先确定：

```text
idempotency
```

如果：

```text
Unknown
```

默认：

```text
No automatic retry
```

超时：

```text
Timeout
```

不能直接推断：

```text
Effect did not happen
```

# 16. Test Matrix

| 类别 | 最低要求 |
|---|---|
| Contract | 100% |
| Unit | 核心模块 ≥95% |
| Security | S0/S1/S2 = 0 |
| Race | 核心动态对象全部覆盖 |
| Recovery | Effect timeout/crash 覆盖 |
| Integration | Search/Workflow/AI/Plugin 全部 |
| Regression | P2.4–P2.8 全部 |
| Soak | ≥30 min |

```text
0
```

# 18. Performance Gate

建议目标：

| 项目 | P95 |
|---|---:|
| System command parse | ≤ 1 ms |
| Target resolution | ≤ 5 ms |
| Policy evaluation | ≤ 2 ms |
| Confirmation creation | ≤ 2 ms |
| Context projection | ≤ 5 ms |
| Process discovery | ≤ 20 ms |
| Window discovery | ≤ 10 ms |
| Clipboard read | ≤ 20 ms |
| Local file validation | ≤ 10 ms |

真实 OS Effect latency 不应作为纯计算组件的固定 SLA。

```text

“把这个文件复制到备份目录”
“关闭这个程序”
“把音量调到 30”
“打开显示设置”
“锁屏”

“每天晚上 11 点把下载目录整理到归档目录”
```

```text

 ↓
PowerShell
 ↓
```

```text
Intent
 ↓
Context
 ↓
System Command
 ↓
Target Resolution
 ↓
Policy
 ↓
Approval
 ↓
launcher-action
 ↓
Effect
 ↓
```
