## 技术设计规范

**状态：FROZEN DESIGN DRAFT**

# 1. 阶段目标

P2.8 建立 Aura Launcher 的正式插件生态层，使插件具备：

- Discovery
- Repository
- Package
- Manifest
- Signature
- Trust
- Compatibility
- Dependency
- Install
- Upgrade
- Rollback
- Uninstall
- Enable / Disable
- Audit
- Health
- Recovery

完整生命周期。

目标不是构建一个“插件下载网站”，而是建立：

```text
Plugin Identity
      ↓
Repository Discovery
      ↓
Package Metadata
      ↓
Signature Verification
      ↓
Trust Evaluation
      ↓
Compatibility Validation
      ↓
Dependency Resolution
      ↓
Install Plan
      ↓
User Approval
      ↓
Controlled Effect
      ↓
Activation
      ↓
Health Monitoring
      ↓
Upgrade / Rollback / Uninstall
```

# 5. PluginIdentity

Plugin 身份必须与 PluginInstance 分离。

```text
PluginId
PluginVersion
PluginInstanceId
PackageDigest
PublisherId
```

例如：

```text
PluginId:
    com.example.todo

Version:
    1.4.0

PublisherId:
    publisher.example

PackageDigest:
    sha256:...

InstanceId:
    runtime-specific
```

禁止使用：

```text
display_name
package_filename
install_path
publisher_name
```

作为 PluginId。

---

# 6. Package 与 Runtime 分离

这是 P2.8 最重要的设计之一。

```text
PluginPackage
    ↓
InstalledPlugin
    ↓
PluginRuntime
```

三者不是同一个对象。

### PluginPackage

表示：

> “磁盘上的一个插件包”。

### InstalledPlugin

表示：

> “当前系统安装状态”。

### PluginRuntime

表示：

> “一个实际运行实例”。

因此：

```text
PluginPackageId
    ≠
PluginInstanceId
    ≠
RuntimeId
```

---

# 7. Package Manifest

Manifest 最低字段：

```yaml
schema_version: 1

plugin:
  id: com.example.foo
  name: Example Foo
  version: 1.2.3

publisher:
  id: example.publisher

runtime:
  type: process
  entrypoint: plugin.exe

compatibility:
  launcher:
    min: 2.8.0
    max: 2.x

platforms:
  - windows-x64

capabilities:
  declared:
    - search.provider
    - action.provider

dependencies:
  - id: com.example.base
    version: "^2.0"

security:
  package_digest: sha256:...
  signature:
    algorithm: ed25519
```

注意：

```text
declared capability
```

只是声明。

不能推出：

```text
granted capability
```

# 8. Trust Model

信任至少分为：

```text
Unknown
Unverified
Verified
Trusted
Blocked
```

建议进一步拆分：

```text
SignatureStatus
PublisherStatus
RepositoryStatus
LocalPolicyStatus
RuntimeHealthStatus
```

最终：

```text
TrustDecision =
    Signature
  + Publisher
  + Repository
  + LocalPolicy
  + Compatibility
  + PackageIntegrity
```

不要使用一个布尔值：

```text
trusted = true
```

作为全部信任状态。

---

# 9. Signature

安装前至少完成：

```text
Package Download
        ↓
Package Hash
        ↓
Signature Verification
        ↓
Publisher Verification
        ↓
Manifest Verification
```

任何一个失败：

```text
InstallPlan = Rejected
```

不得进入 Runtime。

---

# 10. Package Integrity

PackageDigest 是不可变对象。

例如：

```text
sha256:<digest>
```

下载后的实际文件必须满足：

```text
actual_digest == declared_digest
```

否则：

```text
PackageCorrupted
```

禁止：

```text
下载成功
→ 先安装
→ 安装后再验证
```

# 14. Dependency Resolver

依赖解析必须是：

```text
Pure
Deterministic
No Effect
```

输入：

```text
Root Plugin

Version Constraints
Platform

```

输出：

```text
DependencyResolution
```

不能直接安装。

# 15. Dependency Resolution

必须支持：

```text
Exact
Range
Compatible
Optional
Conflict
Missing
```

例如：

```text
A 1.4
 └── B ^2.0

C 3.0
 └── B ^3.0
```

如果无法同时满足：

```text
DependencyConflict
```

必须产生：

```text
InstallPlan = Rejected
```

不得自动选择不满足约束的版本。

# 24. Uninstall


# 25. Disable

Disable 与 Uninstall 必须不同：

```text
Disable:
    保留安装内容
    停止 Runtime
    不参与 Discovery/Execution

Uninstall:
    删除安装内容
```

因此：

```text
Installed = true
Enabled = false
```

是合法状态。


# 45. P2.8 总体不变量

必须全部成立：

```text
I01 PluginId 唯一且稳定
I02 Package != Installation != Runtime
I03 Declared Capability != Granted Capability
I04 Trust != Authority
I05 Repository != Execution
I06 InstallPlan != Effect
I07 AI Proposal != Effect
I08 Workflow Reference != ResolvedAction
I09 下载包必须先验证再安装
I10 安装使用 staging
I11 Upgrade 支持 rollback
I12 failed transaction 不产生 committed state
I13 plugin uninstall 不静默破坏 workflow
I14 broken plugin 不进入正常 execution
I15 plugin lifecycle 全部可审计
I16 dependency resolver 无 Effect authority
I17 trust decision 可解释
I18 all external plugin metadata treated as untrusted data
```
