# Aura-Launcher P2.4 — Test Plan v0.1

## 1. Test strategy

P2.4 validates five properties:

```text
Correctness
Durability
Isolation
Determinism
Recoverability
```

Testing layers:

```text
Unit
→ Component
→ Integration
→ Contract
→ Fault Injection
→ Stress
→ Soak
→ Release Gate
```

## 2. Mandatory commands

Baseline:

```bash
cargo fmt --check
cargo check --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Plugin contract:

```bash
cargo test -p calculator-plugin
cargo test -p example-testplugins --test contract
cargo test -p launcher-plugin-host
```

Release:

```bash
python scripts/release_gate.py --require-baseline
```

## 3. P2.4-A tests

### A-Identity

Must verify:

- same target from different sources collapses to one identity
- normalization is deterministic
- identity does not perform IO
- packaged/AUMID identity is stable
- fallback identity cannot collide across unrelated apps

### A-Catalog

Must verify:

- schema creation
- migration
- one-writer rule
- transaction atomicity
- generation increments once per committed reconcile
- failed transaction leaves previous generation visible
- duplicate observations merge deterministically

### A-Lifecycle

Must verify:

```text
Ready
Stale
Broken
Removed
```

And:

```text
metadata != authority
```

### A-Search

Must verify:

```text
search reads catalog
search does not trigger source discovery
catalog change invalidates relevant cache
```

## 4. P2.4-B tests

### B-Watcher

Scenarios:

```text
watch registration
watch re-registration
watch failure
bounded retry
overflow
duplicate events
```

### B-DirtyRoot

Properties:

```text
queue remains bounded
overflow creates DirtyRoot
DirtyRoot recovers only affected subtree
recovery does not follow reparse points
```

### B-Root lifecycle

```text
root missing
root reappears
permission denied
root changed
```

### B-Generation

Verify:

```text
successful commit → +1
failed batch → unchanged
empty batch → unchanged
```

### B-Soak

Required observations:

```text
CPU
memory
pending events
dirty root count
generation progression
watcher count
```

No linear memory growth.

## 5. P2.4-C tests

### C-Lifecycle

Verify persistence of:

```text
enabled
disabled
quarantined
failure count
```

### C-Trust

Verify that:

```text
Unknown ≠ Trusted
Known ≠ Trusted
manifest metadata cannot self-promote trust
```

### C-Capability

Verify:

```text
unset → denied
allow → explicit persisted approval
deny → explicit persisted denial
manifest changes do not silently upgrade decision
```

### C-Quarantine

Verify:

```text
protocol failures → threshold → quarantine
business failures → no quarantine
restart → quarantine persists
explicit recovery → clear
```

### C-Recovery

Inject corruption into:

```text
plugins.db
plugins.db-wal
plugins.db-shm
backup
```

Verify security state survives when a valid backup exists.

## 6. P2.4-D/E tests

### SDK conformance

Rust and Python reference plugins must both satisfy:

```text
normal
slow
crash
malformed
flood
handshake/version
query_id
frame limits
stdout purity
graceful shutdown
process tree cleanup
```

### CLI

Verify:

```text
init
validate
build
package
install
uninstall
run
inspect
```

Invalid package tests:

```text
missing manifest
invalid version
missing executable
path traversal
duplicate id
unsupported runtime
oversized metadata
```

### Diagnostics

Verify every failure has:

```text
classification
plugin id
query_id where applicable
runtime_id where applicable
protocol_session_id where applicable
elapsed
bounded diagnostic payload
```

No diagnostic path may execute an Effect.

## 7. Cross-cutting tests

### Authority

```text
AI proposal cannot execute directly
Plugin metadata cannot grant capability
MCP metadata cannot grant capability
Cache cannot bypass Resolver
```

### Identity

```text
same semantic app → one canonical candidate
metadata/action merge deterministic
```

### Generation

Test all invalidation paths:

```text
catalog
index
user state
context
ranking
plugin lifecycle
```

### Concurrency

At minimum:

```text
search while catalog reconcile
search while index maintenance
plugin restart while query completes
registry write while diagnostics read
```

## 8. Fault injection matrix

| Fault | Expected |
|---|---|
| catalog DB corrupt | recover/rebuild, no silent unrelated loss |
| plugin registry corrupt | restore backup, otherwise quarantine/rebuild |
| watcher disconnect | re-register |
| event queue overflow | DirtyRoot |
| root disappears | unavailable, index remains queryable |
| root reappears | bounded rescan |
| plugin hangs | timeout + process isolation |
| plugin crashes | Core survives |
| plugin floods | result/frame bound |
| malformed plugin response | reject |
| invalid package | install rejected |
| capability metadata forged | no grant |
| stale catalog record | no authority |

## 9. Performance acceptance

P2.4 must not regress 1.0 budgets.

Record:

```text
idle Private Bytes
startup
app search P50/P95/P99
file search P50/P95/P99
plugin spawn/query/exit
catalog reconcile
index batch
watcher recovery
```

Regression rule:

```text
>5% → warning/review
>10% → fail unless baseline intentionally updated with rationale
```

## 10. Release Gate mapping

```text
G-A  Catalog
G-B  Index
G-C  Plugin Control Plane
G-D  SDK / CLI
G-E  Diagnostics
G-X  Cross-cutting invariants
G-P  Performance / soak
G-R  Documentation / release
```

Any security, topology, authority, contract or zero-warning failure is blocking.
