# Aura Launcher P2.6 验收规范

## Workflow 2.0

---

# 1. COMPLETE 定义

P2.6 必须从：

```text
Linear Workflow
```

升级到：

```text
DAG
+
Durable Runtime
+
Human Approval
+
Trigger Framework
+
Visual Editor
```

同时不破坏：

```text
Action Authority
Plugin Security
Identity
Generation
```

---

# 2. DAG Acceptance

必须：

- [ ] 支持 DAG
- [ ] graph validation
- [ ] branch
- [ ] join
- [ ] bounded parallel execution
- [ ] cycle rejection
- [ ] unreachable-node detection

---

# 3. Condition Acceptance

必须：

- [ ] deterministic
- [ ] pure
- [ ] bounded
- [ ] variable reference
- [ ] invalid expression rejection

---

# 4. Variable Acceptance

必须：

- [ ] Run-scoped
- [ ] input binding
- [ ] output binding
- [ ] branch semantics
- [ ] join semantics
- [ ] no hidden global mutation

---

# 5. Durable Acceptance

必须：

- [ ] Run persisted
- [ ] Step state persisted
- [ ] checkpoints
- [ ] restart recovery
- [ ] interrupted run recovery
- [ ] definition version pinning

禁止：

```text
Executing
→ blind retry
```

---

# 6. Human Approval Acceptance

必须：

- [ ] approval request
- [ ] approve
- [ ] reject
- [ ] cancel
- [ ] expire
- [ ] replay protection
- [ ] run binding
- [ ] node binding
- [ ] session binding

Approval 永远不能变成 capability grant。

---

# 7. Trigger Acceptance

至少：

- [ ] Manual
- [ ] Hotkey
- [ ] Plugin
- [ ] Schedule
- [ ] AI/MCP adapter

但所有 Trigger 必须：

```text
Trigger
→ WorkflowRunRequest
→ Queue
→ Scheduler
```

---

# 8. Visual Editor Acceptance

必须支持：

- [ ] node create
- [ ] node delete
- [ ] edge create
- [ ] edge delete
- [ ] action config
- [ ] input config
- [ ] condition config
- [ ] retry config
- [ ] approval config
- [ ] validation
- [ ] save/load
- [ ] import/export
- [ ] undo/redo

并且：

```text
Editor != Runtime Authority
```

---

# 9. Version Acceptance

必须保证：

```text
Definition v1
Run v1

Definition v2

Run v1 still executes v1
```

禁止隐式 migration。

---

# 10. Security Acceptance

以下全部：

```text
S0 = 0
S1 = 0
S2 = 0
```

必须不存在：

- approval replay
- forged approval
- forged workflow state
- persisted authorization
- persisted ResolvedAction
- trigger bypass
- editor execution bypass

---

# 11. Performance Acceptance

| Metric | Gate |
|---|---:|
| Graph Validation P95 | ≤5ms |
| Scheduler Decision P95 | ≤2ms |
| Checkpoint P95 | ≤10ms |
| Recovery Decision P95 | ≤20ms |
| Approval Event P95 | ≤5ms |
| Queue Enqueue P95 | ≤2ms |

并保持 Launcher：

```text
Idle RSS <= 50MB target
Hard RSS <= 80MB
```

---

# 12. Reliability Acceptance

必须通过：

```text
100 active runs
1000 workflow runs
10000 node transitions
30 min soak
```

以及：

```text
process crash
DB lock
DB corruption
approval replay
node failure
plugin crash
timeout
restart
recovery
```

---

# 13. Architecture Acceptance

必须始终保持：

```text
Workflow
   !=
Action Authority
```

```text
WorkflowDefinition
   !=
ResolvedAction
```

```text
WorkflowRun
   !=
Effect
```

```text
Approval
   !=
Capability
```

```text
Trigger
   !=
Execution
```

---

# 14. Hard Blockers

任一项成立：

1. DAG validator 允许非法 cycle。
2. Scheduler 使用无界并发。
3. checkpoint 保存 ResolvedAction。
4. recovery 对 interrupted Effect 进行 blind retry。
5. Approval 可以跨 Run replay。
6. Definition 更新影响运行中的 Run。
7. Visual Editor 可以直接执行 Action。
8. Trigger 可以绕过 Queue/Scheduler。
9. Workflow 获得 Capability Authority。
10. S0/S1/S2 > 0。
11. required performance budget fail。
12. durable state 在 crash/restart 后损坏。

不得宣布 COMPLETE。
