```text

```

而不是只限制 query response。

# 7. 但这里有一个小问题，我建议现在就写清楚

虽然：

> 单 PluginHandle 最多一个 in-flight query

但目前需要明确：

### 谁负责释放“in-flight”状态？

正常：

```text
query
 ↓
response
 ↓
release
```

timeout：

```text
query
 ↓
timeout
 ↓
kill
 ↓
handle destroyed
```

crash：

```text
query
 ↓
process exit
 ↓
handle destroyed
```

malformed：

```text
query
 ↓
protocol violation
 ↓
kill
```

这些都简单。

真正可能产生问题的是：

```text id="qtxfks"
shutdown
```

发生时 query 还没完成。

建议 Contract 明确：

```text
shutdown while query is in-flight
    → current query is abandoned
    → no late result is accepted
```

这只是一条状态机语义，不需要新增 RPC。
