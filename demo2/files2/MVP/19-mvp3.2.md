### 1. 把性能门禁补齐

    P50 / P95 / P99

这样 MVP3.1 才真正具备一个完整的性能闭环。

# 然后进入 MVP3.2

我不建议直接进入 UI Schema。

下一阶段更合理的是：

```text
MVP3.1 P0
Native Action UI
        │
        ├── P1 performance
        └── real desktop E2E
                │
                ▼
          MVP3.2 Action System
                │
        ┌───────┼────────┐
        ▼       ▼        ▼
     shortcut confirmation context-refresh
                │
                ▼
          richer Action lifecycle
                │
                ▼
      plugin.* Action RPC
```

其中顺序建议固定成：

### MVP3.2-A：Shortcut

让：

```text
ActionDescriptor.shortcut
```

真正进入 UI projection 和键盘处理。

但仍然坚持：

```text
shortcut
   ↓
UI dispatch
   ↓
action_id
   ↓
ActionEngine
```

不能让 shortcut 直接绑定 Effect。

### MVP3.2-B：Confirmation

例如：

```text
execute
shell.execute
process.launch
```

形成：

```text
Action
  ↓
Resolver
  ↓
Ready
  ↓
ConfirmationRequired
  ↓
UI confirmation
  ↓
ActionEngine
```

注意这里需要区分：

```text
CapabilityDenied
ConfirmationRequired
InvalidInput
EffectFailed
```

不能把这些继续混成一个 `disabled_reason`。

### MVP3.2-C：Context-aware refresh

这是三个 P1 里面最值得认真设计的一个。

因为目前已经有：

```text
Explorer
  ↓
ContextSnapshot
  ↓
Context-aware Provider
```

下一步可以把：

```text
ContextSnapshot(t0)
       ↓
Command
       ↓
ActionPanel
```

进一步发展成：

```text
ContextChanged
       ↓
invalidate
       ↓
re-resolve
       ↓
update ActionPresentation
```

但这里应该先冻结**刷新语义**，再写代码，避免 UI 自己监听各种 Windows 状态。

## 一个需要现在就记录的 ADR

我建议趁 MVP3.1 刚完成，新增一个非常小的 ADR，例如：

```text
ADR-0012 — Native Action UI Boundary
```

正式冻结：

> **ActionPanel 只负责 ActionPresentation 的呈现与选择；ActionResolver 负责将不可信 Action 声明转换为可执行对象；ActionEngine 是所有 Effect 的唯一执行入口。**

再把以下内容写成 invariants：

```text
INV-035  UI selection uses stable command_id/action_id
INV-036  UI does not interpret ActionKind/capability
INV-037  UI never executes Effect directly
INV-038  Hidden action is not executable
INV-039  Secondary invalidity does not invalidate Command
```

这样以后进入：

```text
UI Schema
plugin.* RPC
Workflow
AI
MCP
```

时，都必须从这个边界往外扩，而不是重新把 Action 逻辑塞回 UI。
