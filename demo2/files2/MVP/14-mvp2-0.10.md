# 一、RuntimeResolver 这个设计我建议直接定为架构红线

你现在：

```text id="1u2hrb"

        ↓
LaunchPlan

    ├── program
    └── args
```

非常干净。

以后：

```text id="c0f4f1"

runtime.type = node
runtime.type = wasm
```

全部经过：

```text id="s6tzt8"
RuntimeResolver
```

最终统一成：

```text id="bc5l95"
LaunchPlan
```

这意味着 PluginHost 的核心逻辑可以永远保持：

```text id="xkzqdi"
Manifest
 ↓
Resolve Runtime
 ↓
LaunchPlan
 ↓
Spawn
 ↓
Protocol
```

我建议以后禁止出现这种代码：

```rust
match runtime_type {
    RuntimeType::Python => ...

    RuntimeType::Wasm => ...
}
```

出现在：

```text id="launcher-plugin-host/src/host.rs"
```

之类的上层 orchestration 代码里。

**唯一允许出现 runtime dispatch 的地方，就是 RuntimeResolver。**

这非常适合 Agentic Coding。
