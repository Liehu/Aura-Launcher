# 这次拆分里有三个关键点是正确的

## 1. `app.slint` 现在应该真正退化成“编排层”

现在：

```text id="xk7m3v"
app.slint
├── window
├── mode
├── keyboard state
├── callbacks
└── surface composition
```

而不再承担：

```text id="x5yea0"

ResultRow rendering
ActionRow rendering
WorkflowStep rendering
```

这是正确方向。

从你现有架构看，UI 本来就是独立的 Slint presentation 层，而 `launcher-core` 负责 Provider/query orchestration，`launcher-action` 负责唯一的 Action Engine，UI 不应反过来承担这些语义。
