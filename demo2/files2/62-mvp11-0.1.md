# 六十四、其中有一个我建议特别加入：Ranking Explainability

# 六十五、另一个强烈建议：建立 Search Evaluation Corpus

P2 开始不要再靠“我感觉这个排序不错”。

建立固定数据集：

```text
queries/
├── app.txt
├── file.txt
├── folder.txt
├── command.txt
├── plugin.txt
└── mixed.txt
```

每条：

```json
{
  "query": "chr",
  "expected_top": "Chrome"
}
```

然后自动测：

```text
Top-1
Top-3
Top-5
MRR
```

这样以后改 ranking：

```text
代码修改
 ↓
evaluation
 ↓
发现 Top-1 从 92% → 81%
```

立即知道 regression。

这是我认为 P2 最值得提前引入的工程机制之一。
