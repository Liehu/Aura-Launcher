# 二、最值得关注的新问题：你的 T2 已经告诉我们一个很重要的事实

你现在测出来：


这其实是非常有价值的数据。

```text

    │       ≈ 0.16 ms
```

因此目前真正的优化热点不是：

```text

IPC
mpsc
```

而是：

> **首次窗口创建 / Slint window initialization / renderer initialization / native window setup**

这比继续优化 hotkey thread 意义大得多。

而且这直接导致一个架构问题：


例如：

| 指标             |      目标 |
| -------------- | ------: |
| Cold popup P95 | ≤ 35 ms |
| Warm popup P95 | ≤ 10 ms |

不一定现在就采用这些数值，但建议把**冷/热状态作为 benchmark ontology 的一部分**。


