# P2.5 最终不可破坏的 10 条规则

1. `Search != Action Authority`
2. `Provider Metadata != Capability`
3. `Explanation != Authorization`
4. `Completion Order != Ranking Order`
5. `Generation == Committed Data Version`
6. `Boost never creates candidate`
7. `exact > prefix > contains > fuzzy`
8. `FTS5 failure → bounded LIKE fallback`
9. `Pinyin != Identity`
10. `P2.5 != Agent Runtime / Workflow 2.0`

这 36 个 Task 已经可以直接按 **一 Task 一 Agent / 一分支 / 一 PR** 执行。尤其建议不要让 Agent 同时拿 `P25-B02 + C01 + D01`，否则非常容易出现“先写实现、后补契约”的反向开发路径。

其中依赖最关键的是：

```text
P25-001
  ↓
P25-B01
  ↓
P25-B02/B03/B04/B05
  ↓
P25-C01
  ↓
P25-D01/D03
```

也就是说，**P2.5 的第一批 Agent 应优先完成 `P25-000 → P25-002 → P25-A01 → P25-A02 → P25-B01 → P25-B02`**。这部分完成后，Search Intelligence 的核心骨架才真正冻结。
