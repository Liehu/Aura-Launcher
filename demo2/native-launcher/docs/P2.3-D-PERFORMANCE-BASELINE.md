## Methodology（D1）

- Release 构建（opt-level=s, lto=thin, strip=true），本机单环境
- `launcher-bench` 10k 合成文件 + 200 合成应用；每轮 200 次查询 × 4 模板；p50/p95/p99/max
- **真实进程启动（D2）**：`LAUNCHER_SNAPSHOT=<bmp>` 单帧模式，进程 spawn → show → 固定 900ms 渲染 settle → 抓帧退出；启动 = wall − 900ms，多次取样取中位数
- **内存（D4）**：PowerShell Get-Process（WorkingSet/PrivateMemorySize64）+ 进程内 GetProcessMemoryInfo(PrivateUsage)
- **soak（D5）**：launcher-bench soak 100k ops（趋势/阶梯检测）＋ 真实 UI popup 1000 次显隐（增长 < 10MB 判定）；30min/4h 长剖面用 C11 `LAUNCHER_SOAK_SECONDS=1800/14400`
- 回归判定（D6）：thresholds.json budgets 为绝对上限（非 baseline-relative）；G10（D7）每次 release gate 重跑 bench 并全字段判定
