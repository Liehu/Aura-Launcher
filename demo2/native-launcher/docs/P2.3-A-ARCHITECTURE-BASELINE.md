## 3. 权威链（冻结）

```text
Producer（UI/Workflow/Agent/Plugin/MCP）
    ↓ ActionProposal / ActionDescriptor
ActionResolver
    ↓
launcher-action::validate()   ← 唯一 confirmation/capability 闸门
    ↓
launcher-action::execute()    ← 唯一 Effect 路径
    ├─ system.*   → OS（ShellExecute/clipboard/paste）
    ├─ plugin.*   → PluginBroker → RuntimeManager → 插件进程
    └─ mcp.*      → McpExecutor → RuntimeManager → MCP server
```

Search / Cache / Favorites / Context / Icon 全部位于此链**上游**，只有信号权，无执行权。

## 4. 1.0 冻结范围

- 数据面：File Index（增量）+ Application Catalog（聚合+持久化）
- 搜索面：identity dedup → RankingWeights + usage/favorite/context boost → Top-K
- 生命周期：单实例 / 启动健康标记 / 崩溃环降级 / schema_version / 卸载保留策略
- 用户面：Favorites(Ctrl+D) / 空查询 recents / Settings 热重载 / Workflows 目录

**明示不在 1.0**：Agent 接线（实验性 crate）、MSIX/签名、Recovery Mode UI、
TimeBucket、Query Cache SingleFlight、P2.1-C Provider Contract v2 主体。
